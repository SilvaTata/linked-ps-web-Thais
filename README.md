## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte do processo seletivo da Empresa Júnior da Universidade Federal de São João del-Rei (UFSJ).

O projeto consiste em uma página institucional (landing page) para um consultório de psicologia.

A página conta com as seguintes seções:

- Início: apresentação do consultório.
- Nossos Serviços: descrição do trabalho realizado pelo consultório.
- Horários de Atendimento: tabela com horários de funcionamento.
- Feedbacks: avaliações de pacientes.
- Contato & Localização: informações de como entrar em contato com o local.
- Rodapé: links de acesso rápido.

## 🚀 Como executar o projeto

Obs.: é necessário instalar a extensão Live Serve no VsCode

1. Baixe o arquivo .zip do código

2. Descompacte a pasta e abra pelo VsCode

3. Clique com o botão direito sobre o arquivo index.html e selecione "Open with Live Server"

## 🛠️ Tecnologias e ferramentas

As tecnologias utilizadas no desenvolvimento foram:

- HTML — estruturação da página
- CSS — estilização da página
- JavaScript — implementação de interações com o front-end
- Git e GitHub — versionamento e hospedagem do código

## 💡 Decisões técnicas

1. Utilizar HTML e CSS: Optei por utilizar HTML e CSS para a estruturação e estilização da página devido à minha maior familiaridade com essas tecnologias.

2. Remoção das curvas na primeira página: Inicialmente, a primeira página possuía elementos com curvas no layout. No entanto, não consegui configurar a imagem para acompanhar essas curvas de forma visualmente adequada. Para evitar um resultado desalinhado ou visualmente truncado, optei por remover as curvas e manter uma composição mais simples e consistente.

3. Pouca utilização do JavaScript: A maior parte das funcionalidades solicitadas foram implementadas utilizando apenas HTML e CSS. Por isso, o JavaScript foi utilizado de forma pontual, principalmente para adicionar algumas interações à página, como a rolagem suave entre seções e o comportamento do formulário.
